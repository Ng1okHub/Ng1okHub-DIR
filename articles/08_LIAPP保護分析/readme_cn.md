# 文章简介

本文以 LIAPP 保护分析为案例，记录一次应用安全分析的工作脉络与经验。内容聚焦于分析过程和思考方式，不在此介绍中展开文章中的具体知识与技术细节。

## 做了什么

整理了从观察问题、进行分析到归纳结果的过程，并记录实际分析中累积的经验。

## 解决了什么问题

提供一个完整案例，帮助读者理解安全分析工作如何展开、如何整理思路，并为之后遇到类似分析任务提供参考。

## 适合哪些人阅读

- 对应用安全或逆向分析有兴趣的读者
- 正在学习安全分析流程与分析思路的人
- 希望透过实际案例了解分析工作的人
