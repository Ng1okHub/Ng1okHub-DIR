# 文章簡介

本文以 LIAPP 保護分析為案例，記錄一次應用安全分析的工作脈絡與經驗。內容聚焦於分析過程和思考方式，不在此介紹中展開文章中的具體知識與技術細節。

## 做了什麼

整理了從觀察問題、進行分析到歸納結果的過程，並記錄實際分析中累積的經驗。

## 解決了什麼問題

提供一個完整案例，幫助讀者理解安全分析工作如何展開、如何整理思路，並為之後遇到類似分析任務提供參考。

## 適合哪些人閱讀

- 對應用安全或逆向分析有興趣的讀者
- 正在學習安全分析流程與分析思路的人
- 希望透過實際案例了解分析工作的人
