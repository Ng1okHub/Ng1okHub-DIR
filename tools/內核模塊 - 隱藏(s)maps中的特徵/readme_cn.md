# hide_maps：隐藏 maps / smaps 特征的内核模块

[📖 繁體中文](readme.md)　|　[📖 简体中文](readme_cn.md)

这是一个针对 `/proc/<pid>/maps` 与 `/proc/<pid>/smaps` 可见特征做处理的内核模块。它的价值不在於单纯改一行输出，而在于把一些原本容易被观察到的 VMA 痕迹收敛掉，让特征暴露不再那么直接。

## 🧭 它做了什么

`hide_maps` 主要处理两类事情：一类是改写显示出的映射权限，另一类是把命中特定 pathname 特征的 VMA 记录直接隐藏掉。从读者角度来看，重点不是它怎么挂进去，而是它确实把 `maps` / `smaps` 这层的可见特征变得更干净。

## 🪟 看到的结果是什么

这个工具最直接的成果，是命中的记录可以不再出现在输出里，或以不同的显示权限呈现。对需要处理 `memfd`、临时路径或映射权限暴露的人来说，这类结果本身就很实用。

它更适合作为一个辅助型处理工具来看：重点是先把 `maps` / `smaps` 这条线上的可见痕迹收敛掉，让后续分析或处理更容易展开。

## 🎯 适用场景

如果你正在处理 `maps` / `smaps` 里的可见特征，尤其是 pathname 或权限层面的暴露，这个工具可以帮到你。

## 💬 一句话说完

`hide_maps` 是一个专门用来收敛 `maps` / `smaps` 可见特征的内核模块，重点在于把映射权限与 pathname 痕迹处理得更不显眼。
