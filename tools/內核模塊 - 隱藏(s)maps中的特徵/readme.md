# hide_maps：隱藏 maps / smaps 特徵的內核模塊

這是一個針對 `/proc/<pid>/maps` 與 `/proc/<pid>/smaps` 可見特徵做處理的內核模塊。它的價值不在於單純改一行輸出，而在於把一些原本容易被觀察到的 VMA 痕跡收斂掉，讓特徵暴露不再那麼直接。

## 🧭 它做了什麼

`hide_maps` 主要處理兩類事情：一類是改寫顯示出的映射權限，另一類是把命中特定 pathname 特徵的 VMA 記錄直接隱藏掉。從讀者角度來看，重點不是它怎麼掛進去，而是它確實把 `maps` / `smaps` 這層的可見特徵變得更乾淨。

## 🪟 看到的結果是什麼

這個工具最直接的成果，是命中的記錄可以不再出現在輸出裡，或以不同的顯示權限呈現。對需要處理 `memfd`、臨時路徑或映射權限暴露的人來說，這類結果本身就很實用。

它更適合作為一個輔助型處理工具來看：重點是先把 `maps` / `smaps` 這條線上的可見痕跡收斂掉，讓後續分析或處理更容易展開。

## 🎯 適用場景

如果你正在處理 `maps` / `smaps` 裡的可見特徵，尤其是 pathname 或權限層面的暴露，這個工具可以幫到你。

## 💬 一句話說完

`hide_maps` 是一個專門用來收斂 `maps` / `smaps` 可見特徵的內核模塊，重點在於把映射權限與 pathname 痕跡處理得更不顯眼。
