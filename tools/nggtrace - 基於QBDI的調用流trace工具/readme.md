# nggtrace：基於 QBDI 的調用流 trace 工具

[📖 繁體中文](readme.md)　|　[📖 简体中文](readme_cn.md)

nggtrace 的定位很直接，就是把目標函數周圍的調用流記錄下來，方便用來看檢測點、行為鏈路，或者函數之間到底是怎麼串起來的。對逆向分析來說，它的價值不在於多一個 trace，而在於把原本分散的結果整理成可回看的結構。

## 🧭 它做了什麼

這套工具把調用流 trace 和配套查看界面放在一起。前者負責把目標函數相關的調用過程記錄下來，後者則把這些結果整理成可以瀏覽、搜索、交叉引用與回看的界面，讓分析不再停留在零散日志。

## 🪟 看到的結果是什麼

最直觀的成果，是可以直接從界面裡看函數之間的調用關係，而不是只盯著一長串文本輸出。這讓很多原本難整理的過程，能更快收斂成一條可讀的脈絡。

![nggtrace-ui 調用流視圖](images/overview.png)

除了調用流本身，這套 UI 也把搜索和定位能力補得比較完整。對做行為追蹤的人來說，這意味著你不只是能看到流程，還能更快找到想關注的函數、事件或上下文。

![nggtrace-ui 搜索視圖](images/search.png)

另一個實用點，是它把一些更適合做總覽觀察的內容獨立出來。當你不是只想看單一路徑，而是想知道某類外部函數、事件或調用模式的分布時，這種統計視圖會更有價值。

![nggtrace-ui 統計視圖](images/stats.png)

## 🎯 適用場景

如果你需要一個能把函數調用關係、搜索定位和結果回看整合起來的輔助工具，這個工具可以幫到你。

## 💬 一句話說完

nggtrace 把函數調用流 trace 和可視化查看整合在一起，能更快幫你整理檢測點與 APP 行為脈絡。
